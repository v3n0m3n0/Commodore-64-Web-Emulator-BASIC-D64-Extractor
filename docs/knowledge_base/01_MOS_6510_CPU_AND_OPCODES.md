# 01. MOS 6510 / 6502 CPU & Opcode Architecture Reference

> **Source:** [mist64/c64ref](https://github.com/mist64/c64ref) (Michael Steil, Lee Davison, Commodore specs)

## 1. Overview
The Commodore 64 uses the **MOS Technology 6510** microprocessor, an 8-bit CPU based on the core 6502 architecture clocked at:
- **PAL:** 0.985248 MHz (1 PAL clock cycle ≈ 1.0149 µs)
- **NTSC:** 1.022727 MHz (1 NTSC clock cycle ≈ 0.9778 µs)

The 6510 adds an integrated 6-bit parallel I/O port located at memory addresses `$0000` (Data Direction Register) and `$0001` (Data Register), which controls the PLA memory bank switching.

## 2. Registers
| Register | Size | Description |
|---|---|---|
| **A** | 8-bit | Accumulator for arithmetic and logical operations |
| **X** | 8-bit | Index Register X (can also be transferred to/from SP) |
| **Y** | 8-bit | Index Register Y |
| **SP** | 8-bit | Stack Pointer (hardwired to page 1: `$0100-$01FF`, grows downward) |
| **PC** | 16-bit | Program Counter (`$0000-$FFFF`) |
| **P** | 8-bit | Processor Status Flags: `N V - B D I Z C` |

### Status Register Flags (P)
- **N (Negative, bit 7):** Set if result of operation has bit 7 high.
- **V (Overflow, bit 6):** Set if signed arithmetic operation resulted in an overflow.
- **- (Unused, bit 5):** Always pushed as 1 on stack during PHP/BRK.
- **B (Break Command, bit 4):** Set if interrupt was generated by software BRK opcode.
- **D (Decimal Mode, bit 3):** When set, ADC and SBC operate in Binary Coded Decimal (BCD) mode.
- **I (Interrupt Disable, bit 2):** When set, maskable IRQ interrupts are ignored.
- **Z (Zero, bit 1):** Set if result of operation equals zero.
- **C (Carry, bit 0):** Set if addition resulted in carry out or subtraction without borrow.

## 3. Addressing Modes & Page Crossing Cycle Penalties
The 6502 features 13 addressing modes:
1. **Accumulator (A):** 1 byte, 2 cycles.
2. **Implied (impl):** 1 byte, 2 cycles (`NOP`, `TAX`, `INX`, etc.).
3. **Immediate (#imm):** 2 bytes, 2 cycles (`LDA #$10`).
4. **Zero Page (zp):** 2 bytes, 3 cycles (`LDA $20`).
5. **Zero Page,X (zp,X):** 2 bytes, 4 cycles (`LDA $20,X`).
6. **Zero Page,Y (zp,Y):** 2 bytes, 4 cycles (`LDX $20,Y`, `STX $20,Y`).
7. **Absolute (abs):** 3 bytes, 4 cycles (`LDA $1234`).
8. **Absolute,X (abs,X):** 3 bytes, 4 cycles + **1 cycle penalty** if page boundary is crossed.
9. **Absolute,Y (abs,Y):** 3 bytes, 4 cycles + **1 cycle penalty** if page boundary is crossed.
10. **Indirect (ind):** 3 bytes, 5 cycles (`JMP ($1234)` - includes famous $xxFF page boundary wrap bug).
11. **Indexed Indirect ((zp,X)):** 2 bytes, 6 cycles (`LDA ($20,X)`).
12. **Indirect Indexed ((zp),Y):** 2 bytes, 5 cycles + **1 cycle penalty** if page boundary is crossed (`LDA ($20),Y`).
13. **Relative (rel):** 2 bytes, 2 cycles if branch not taken, 3 cycles if branch taken within page, **4 cycles** if branch crosses page boundary.

## 4. Official & Undocumented Opcodes Reference Table
| Mnemonic | Hex | Mode | Cycles | Page Penalty | Type | Description |
|---|---|---|---|---|---|---|
| **ADC** | 69, 65, 75, 6D, 7D, 79, 61, 71 | Various | 2-6 | Yes | Official | Add Memory to Accumulator with Carry (supports BCD mode) |
| **SBC** | E9, E5, F5, ED, FD, F9, E1, F1 | Various | 2-6 | Yes | Official | Subtract Memory from Accumulator with Borrow |
| **LAX** | A7, B7, AF, BF, A3, B3 | zp, zpY, abs, absY, (zp,X), (zp),Y | 3-5 | Yes | Undocumented | Load A and X simultaneously from memory (`LDA` + `LDX`) |
| **SAX** | 87, 97, 8F, 83 | zp, zpY, abs, (zp,X) | 3-5 | No | Undocumented | Store A AND X into memory (`A & X -> Mem`) |
| **DCP** | C7, D7, CF, DF, DB, C3, D3 | zp, zpX, abs, absX, absY, (zp,X), (zp),Y | 5-8 | No | Undocumented | Decrement memory and compare with A (`DEC` + `CMP`) |
| **ISC** | E7, F7, EF, FF, FB, E3, F3 | zp, zpX, abs, absX, absY, (zp,X), (zp),Y | 5-8 | No | Undocumented | Increment memory and subtract from A with borrow (`INC` + `SBC`) |
| **SLO** | 07, 17, 0F, 1F, 1B, 03, 13 | zp, zpX, abs, absX, absY, (zp,X), (zp),Y | 5-8 | No | Undocumented | Shift Left memory and OR with A (`ASL` + `ORA`) |
| **RLA** | 27, 37, 2F, 3F, 3B, 23, 33 | zp, zpX, abs, absX, absY, (zp,X), (zp),Y | 5-8 | No | Undocumented | Rotate Left memory and AND with A (`ROL` + `AND`) |
| **SRE** | 47, 57, 4F, 5F, 5B, 43, 53 | zp, zpX, abs, absX, absY, (zp,X), (zp),Y | 5-8 | No | Undocumented | Shift Right memory and EOR with A (`LSR` + `EOR`) |
| **RRA** | 67, 77, 6F, 7F, 7B, 63, 73 | zp, zpX, abs, absX, absY, (zp,X), (zp),Y | 5-8 | No | Undocumented | Rotate Right memory and ADC to A with Carry (`ROR` + `ADC`) |
| **LAS** | BB | abs,Y | 4 | Yes | Undocumented | Load A, X, SP with Memory AND Stack Pointer (`A, X, SP = Mem & SP`) |
| **ALR** | 4B | #imm | 2 | No | Undocumented | AND Accumulator with immediate, then Shift Right (`A = (A & #imm) >> 1`) |
| **ANC** | 0B, 2B | #imm | 2 | No | Undocumented | AND Accumulator with immediate, copy bit 7 to Carry flag |
| **ARR** | 6B | #imm | 2 | No | Undocumented | Complex AND immediate + Rotate Right with BCD decimal flag adjustments |
| **SBX** | CB | #imm | 2 | No | Undocumented | Subtract immediate from (A AND X) and store result in X (`X = (A & X) - #imm`) |
| **NOP** | 1A, 3A, 5A, 7A, DA, FA, 04, 14, 34, 44... | Various | 2-4 | Yes | Undocumented | Double / Triple byte NOPs (safely skips 1 or 2 operand bytes) |

## 5. Hardware Reset & Interrupt Vector Table
| Vector | Address | C64 Default Pointer | Description |
|---|---|---|---|
| **NMI** | `$FFFA-$FFFB` | `$FE43` (points to `$0318`) | Non-Maskable Interrupt (RESTORE key, CIA2 Timer A/B, IEC) |
| **RESET**| `$FFFC-$FFFD` | `$FCE2` | System Cold Reset Entry point |
| **IRQ/BRK** | `$FFFE-$FFFF` | `$FF48` (points to `$0314`) | Maskable Interrupt / Software Break (VIC-II raster, CIA1 60Hz) |
