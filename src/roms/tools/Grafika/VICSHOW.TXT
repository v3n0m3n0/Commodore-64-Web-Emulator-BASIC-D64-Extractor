2.Introduction
ออออออออออออออ
This utility was fully designed by Piotr Tracz a.k.a KaeMEGie/Albion.
VicShow allow you display oryginal Commodore 64's FLI & FLI-lace
graphic formats using any ms-dos compatible machines. The engine is
based upon my VicStudio C64 - powerfull converter for C64 which can convert
all kind of graphic from C64>PC / PC>C64. The whole program is totally
written in 80x86 assembler which made it very short and fast - I do
hate all programs which doesn't do anything special and takes megabytes
of my HDD space, Windowz'95 is my favourite :)

3.Hardware Requirments
ออออออออออออออออออออออ
VicShow hasn't big requirments - everything it needs is an ms-dos
compatible machine with min.80386 processor and standart VGA graphic card -
monsters kinda Matrox Milenium II are strongly not recomendet! :)

4.Using
อออออออ
VicShow is a command-line utility designed to be used with a Norton
Commander (and all similars) program.

vicshow.exe [option] filename_of_c64_graphic_file

where option can be:
-m :enables mixed colors during viewing FLI-lace graphic

There is no any restrictions to the filename_of_c64_graphic_file as
VicShow will automatically decide does file is supported C64 graphic
or not. Despite, I sugest you will give all your C64's gfx files the
same extension, feg. ".f64".

Meantime,graphic is showed you can press key "F10" and VicShow
will save it as a uncompressed 256 colors BMP file

5.Supported Graphic Formats
อออออออออออออออออออออออออออ
FunPainter II (uncompressed)
FLI-Designer
FLI-Draw

As the C64 graphic files has no headers it's quite hard to determine
file format - VicShow checks only the first two bytes (in C64 used
as load-address). Noting unexpected doesn't take place if you order
it to show any not C64 gfx file which it will determine as C64 gfx!
